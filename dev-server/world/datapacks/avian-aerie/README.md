# avian-aerie (world data pack)

The Aerie's build (#21): a rock crag veined with gold, a nest of logs on top around a blackstone-and-gold
capture pad, a beacon whose beam marks it from anywhere, signal fires and banners on the rim, and a
staircase (three wide, wall and lanterns on the open side) spiralling up from a lit plaza. Generated by `tools/aerie/build.js`; don't edit the
function by hand: change the script and run `node tools/aerie/build.js`.

Build it, standing nowhere near (it clears a 33×32×33 box first, so building again replaces the old one), from the console:

    execute positioned 0 142 190 run function avian:aerie/build

The position is the first air block above the ground at the crag's centre. Today: 0, 142, 190 in
`world`, south of spawn in the warzone. `avian:aerie/clear` at the same position removes it.
**Move the capture zone with it:** `plugins/AvianFactions/aerie.conf` (`center-x`/`center-z`, radius 10.5,
y from the position +21 to +30, and the two `signs`).

Copied into `run/world/datapacks/` by `./dev start` like the rest of `dev-server/`.
